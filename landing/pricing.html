Pricing

The CLI is free and runs locally. Team features are coming later; the free CLI stays free.

The CLI
Free

The whole tool, not a cut-down trial. Unlimited checks, no card, no account. rulereceipt check runs on your machine and makes zero network calls.

This part stays free. It’s source-available — you can read every line it runs.

For teams
Later

An org-wide, hosted view — trends across people and repos, compliance reports for audits and vendor reviews — is in development. It’s a genuinely different product from the local check.

We’ll announce it with a real price when it exists. We’re not quoting a number for something that isn’t built. Get in touch if you need it early.

No asterisks

The questions people actually ask about the price.

Will the CLI start costing money later?

No. We make money from the paid Team tier, never from the CLI. There’s no paywall part-way through a command, and no feature that gets pulled behind a subscription later. The free CLI stays free.

Is “free” just a launch promotion?

No. It’s not free “for now” and it isn’t a time-limited offer — the local CLI is the free product, permanently. The Team tier is how the project is funded, and it’s a separate, hosted thing.

Do I need an account or an API key?

No account, ever, to use the CLI. For the rules that need judgment you can supply the same Anthropic API key your Claude Code setup already uses — rules naming something concrete (a branch, a file, a command) are checked locally with no key and no cost.

If the Team tier’s pricing is ever set, it’ll be announced clearly and in advance — never a silent switch. Want a heads-up? There’s a one-email notify option on the home page.
