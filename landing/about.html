The Receipt Keeper

keeps the evidence honest

I run Claude Code daily. I write rules into CLAUDE.md. And for a long time, I had no real way to know whether they were actually followed — or just quietly skipped.

The things that actually scare a developer aren't bugs. They're the quiet ones: a rule you were sure was followed, until it wasn't. A production database gone because an agent "took a shortcut." A public repo, a forgotten .env, client data exposed — and nobody finds out until it's too late.

Vibe coding with Claude Code is genuinely good. Trusting it to follow my own rules, without checking, wasn't. So I built the thing that checks — evidence, not a guess.
