# Contributing

This is source-available software, not an open-source project — see
[LICENSE](./LICENSE) and [NOTICE.md](./NOTICE.md).

**Code contributions aren't accepted.** Pull requests will be closed
without review. That isn't about the quality of the work; the licensing
and provenance of this codebase are deliberately kept simple and
single-owner.

**Bug reports and questions are genuinely welcome.** If the tool gets
something wrong — especially a false positive, which is the failure mode
this project cares most about — open an issue or email
hello@rulereceipt.dev. A real example (the rule text and what actually
happened in the session) is far more useful than a description.

For security issues, see [SECURITY.md](./SECURITY.md) — please report
those privately rather than in a public issue.
